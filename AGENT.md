\# Project: Demo website for a premium beauty salon



\## Goal

Create a polished demo website for a fictional premium beauty salon that can be shown to potential clients as an example of a high-end service business website.



The website must look expensive, elegant, modern, feminine, premium, and convenient.  

It should feel like a real salon website made for a serious beauty business, not like a simple template.



The site is a demo project for portfolio / presentation purposes, so the brand, texts, and content can be fictional but must look realistic and convincing.



\---



\## Brand concept

Create a fictional beauty salon brand:



\- Name: \*\*Lumière Beauty Studio\*\*

\- Tagline: \*\*Premium beauty, comfort, and care\*\*

\- Positioning: high-end beauty salon with manicure, pedicure, brows, lashes, cosmetology, hair styling, makeup, and spa-style service

\- Style: premium, elegant, soft luxury

\- Visual mood: clean, expensive, feminine, calm, aesthetic, Instagram-friendly

\- Audience: women 20–45, clients who value comfort, aesthetics, premium service, and easy online booking



\---



\## General design direction

The website should feel premium and expensive.



\### Visual style

\- Modern, elegant layout

\- Clean typography with a luxury feel

\- Lots of whitespace

\- Soft premium color palette

\- Rounded details only where appropriate

\- Subtle layered gradients

\- Elegant micro-interactions

\- Smooth animations

\- Glass / glow / soft light accents can be used carefully, but do not overdo them

\- Avoid cheap-looking template aesthetics



\### Suggested color palette

Use a premium feminine palette, for example:

\- warm white / ivory background

\- soft beige / champagne

\- muted blush

\- dark graphite / deep taupe for text

\- soft gold accents

\- optional dusty rose accent



\### Typography

Use elegant web-safe or premium-looking Google Fonts.

Suggested pairing:

\- heading font: elegant serif or editorial style

\- body font: clean modern sans-serif



The typography should look expensive and readable.



\---



\## Technical direction

Build the project as a modern responsive website.



\### Requirements

\- Responsive for mobile, tablet, laptop, desktop

\- Fast loading

\- Clean structure

\- Production-ready code style

\- Reusable components

\- Well-organized folders

\- Easy to edit later



\### Important

\- Do not use copyrighted brand assets

\- Use royalty-free / placeholder / generated demo images

\- Use realistic salon imagery: manicure, salon interior, cosmetics, lashes, brows, hairstyle, treatment room, reception, waiting area

\- If images are needed, use elegant placeholders and structure the code so they can be replaced later



\---



\## Site structure

Create a multi-section premium website.  

A one-page structure is allowed, but it must feel like a real website with multiple navigation sections.  

If helpful, use internal routes/pages too.



Recommended structure:



1\. Home

2\. Services

3\. Price List

4\. Gallery / Works

5\. About / Why us

6\. Team / Specialists

7\. Reviews

8\. Location / Contact / Booking



If easier, make:

\- homepage with major sections

\- separate `/services`

\- separate `/prices`

\- separate `/contact`
