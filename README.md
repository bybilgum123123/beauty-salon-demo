# Lumière Beauty Studio

Демонстраційний односторінковий сайт преміального салону краси. Усі контактні дані, ціни, відгуки та імена майстрів — приклади для презентації.

## Перегляд

```bash
npm install
npm run dev
```

Для готової статичної версії виконайте `npm run build`. Результат з’явиться в `dist/`; перевірити його можна через `npm run preview`.

## Де змінювати вміст

- Тексти, контакти, розділи, послуги та імена майстрів: `index.html`.
- Ціни й відгуки: об’єкти `priceData` і `reviews` у `script.js`.
- Кольори й розміри: `premium.css`; базові стилі — `styles.css`. Локальні шрифти Manrope і Playfair Display: `fonts.css` та `assets/fonts/`, разом із ліцензіями.
- Фотографії та hero-відео: каталог `assets/`. Для першого екрана використовуються `lumiere-hero.mp4` і `lumiere-hero-poster.webp`; відео зупиняється поза екраном та в режимі зменшеного руху.
- Монохромний анімований фон переходу: `src/ui/GradientWave.jsx`. Його кольори й параметри задаються в `src/ui/mount-gradient-wave.jsx`. React і WebGL завантажуються лише поблизу цього розділу; без WebGL залишається CSS-фон.
- Картки послуг — звичайна розмітка в `index.html`. Меню, прайс, відгуки, керування відео й демо-форма працюють через `script.js`.

## Публікація демо

Команда збірки для Vercel: `npm run build`, каталог результату: `dist`. Публікуйте лише цей каталог: вихідні файли розробки до нього не копіюються.

Форма перевіряє поля й показує демо-підтвердження. Дані не зберігаються та не надсилаються; телефон, email, адреса й графік роботи позначені як приклади. Без JavaScript вміст доступний, а кнопка демо-форми вимкнена.

## Перед публікацією для реального салону

Підставте справжні адресу, телефон, години роботи, фото команди, відгуки та ціни. Форма запису зараз показує демонстраційне підтвердження і **не надсилає дані**. Для реального запису підключіть CRM, поштовий сервіс або бекенд у обробнику `#booking-form` у `script.js`.
