# Lumière Beauty Studio

Демонстраційний односторінковий сайт преміального салону краси. Усі контактні дані, ціни, відгуки та імена майстрів — приклади для презентації.

## Перегляд

```bash
npm install
npm run dev
```

Для готової статичної версії виконайте `npm run build`. Результат з’явиться в `dist/`; перевірити його можна через `npm run preview`.

## Де змінювати вміст

- Тексти, контакти, розділи, послуги та імена майстрів: `index.html`.
- Ціни й відгуки: об’єкти `priceData` і `reviews` у `script.js`.
- Кольори, шрифти та розміри: змінні на початку `styles.css`.
- Фотографії: каталог `assets/`. Замінюйте файли з тими самими назвами або змінюйте шляхи в `index.html` та `src/enhancements.jsx`.
- Анімації та галерея: `src/enhancements.jsx`, стилі — `enhancements.css`. Компоненти в `src/reactbits/` адаптовані з [React Bits](https://reactbits.dev/); умови використання збережені в `src/reactbits/LICENSE.md`.

## Перед публікацією для реального салону

Підставте справжні адресу, телефон, години роботи, фото команди, відгуки та ціни. Форма запису зараз показує демонстраційне підтвердження і **не надсилає дані**. Для реального запису підключіть CRM, поштовий сервіс або бекенд у обробнику `#booking-form` у `script.js`.
